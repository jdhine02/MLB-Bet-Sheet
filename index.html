SP Matchup Grade A-F

Every batter gets a daily matchup grade vs today SP. Shown as colored badge on game tabs and hit props table.

AStrong matchup (score 80+) — hittable SP, favorable platoon, hot batter
BGood matchup (score 65+) — above average edge
CNeutral (score 50+) — proceed with caution
DTough matchup (score 35+) — elite SP or bad platoon
FAvoid (<35) — ace SP + wrong side of platoon

Hover badge for breakdown. Factors: SP BAA (season + L5), platoon advantage, career H2H vs this SP, SP K/9, SP recent form (L5 ERA). xwOBA, K%, F-Strike%, Barrel%, Groundball%.

Parlays

🔒 Small 3-leg all LOCK 0.5u target +150 to +250 any prop type 🔒 Big 5-leg all LOCK 0.25u target +1000+ any prop type

Both parlays require ALL legs to be 🔒 LOCK (model edge ≥+8% above market). Any prop type eligible — Hit, K, HRBI, or TB. HR excluded (too many variables). If fewer than 3 locks exist, parlay shows "No locks available." Big parlay targets 5 locks; small targets 3.
