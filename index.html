Overview — Prop Tables (Model v11)

🔥 Hit Streaks — top 12 active streaks 💣 HR badge FD + Best odds 🎯 Hit Props — top 12 by composite score SP grade A-F AVG≥.240 no L/L FD+Best 💣 HR Props — top 12 park factor + EV + Barrel% FD + Best 💚 H+R+RBI — sorted by HRBI/G L5 O0.5/O1.5 dynamic L5 R/RBI/HRBI cols ⚠ K Props — SP box score only opp team K% adjusts line ±0.5 🪜 Ladder/SGP — 1 best play each side by side 🚫 NRFI — A-F grade all games ⭐ = both SPs BAA<.240 + K9≥8

Composite score = AVG×200 + OBP×100 + SP_BAA×150 + platoon + L5_form×40 + streak sweet spot. Varies daily with matchup — same player ranks differently each day.

SP K Grading -- Critical Rule

K props use SP pitcher box score ONLY (mlb_sp_ks.csv). Never the batter box score -- that overcounts by including reliever Ks attributed to the starter's spot in the order.

Example (Apr 15): Jess Luzardo showed 8K from batter-side (wrong -- included reliever Ks). Actual pitcher box: 4K. Bet slip confirmed 4K. Corrected K prop rate: 58.6% (17W/12L) not the wrong 96.6%.

Source: data[side]['players'][sp_pid]['stats']['pitching']['strikeOuts'] -- K count locked the moment SP exits.

SP Matchup Grade A-F

Every batter gets a daily matchup grade vs today's SP. Shown as colored badge on game tabs and hit props table.

A Strong matchup (score 80+) — hittable SP, favorable platoon, hot batter   B Good (65+)   C Neutral (50+)   D Tough (35+)   F Very tough (<35) — elite SP + bad platoon

Hover badge for breakdown. Factors: SP BAA (season + L5), platoon advantage, career H2H vs this SP, SP K/9, SP recent form (L5 ERA).

How Results Tab Populates Daily

  1. Run mlb_pipeline.py -> pulls yesterday's box scores, SP Ks, game scores into CSVs
  2. Run mlb_grade_yesterday.py -> reads previous day picks -> grades each -> appends to mlb_bets_master.csv
  3. Run mlb_build.py -> Results tab reads master CSV -> shows rolling 7/30/season P&L

Yesterday's SP K actuals and game scores always show on Results tab from sp_ks + linescore even before master CSV is graded.
